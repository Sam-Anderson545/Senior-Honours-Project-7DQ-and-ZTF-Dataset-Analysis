# Senior-Honours-Project-7DQ-and-ZTF-Dataset-Analysis
Code for identifying quasars in outburst from a dataset containing light curve data spanning seven decades. Scripts for fitting models, plotting light curves included.

A few notes:
- I'm not under the impression I've mastered python by any means - I'm sure the code in this repository could be improved in many places! It's here primarily as a record of what I've done.
- To run the code, you need access to the 7DQ database and ZTF data. I haven't given access to any data here, and a significant amount of the scripts rely on locally stored data files. Change file paths in the code as appropriate.
- I've also left most redundant code as docstrings in the files, again as a record of my thinking and workflow. This does make it a bit messy but I'm afraid I've not yet put in the work to clean the code and smoothen it all out.
